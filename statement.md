# Project Statement

## Problem Statement

Rolling several dice repeatedly by hand takes time and makes it difficult to collect useful statistics. A simple computer program can perform the same experiment quickly and show the results in an organized way.

## Scope

The project simulates multiple dice rolls. The user decides the number of dice, the number of sides on each die and the number of times to repeat the experiment. The program calculates and displays basic statistics from the generated totals.

The project is limited to a command-line interface and does not use a database or JSON storage.

## Target Users

- Beginner Python students
- Students learning probability through simulation
- Users who want a simple dice experiment

## High-Level Features

- Multiple dice creation
- Random rolling
- Repeated simulation
- Total calculation
- Statistical summary
- Frequency count
- Input validation
